# D1：跨数据集确认前的数据与权重核验

2026-10-15接续R2，下一目标为独立数据确认。本轮先完成可执行性与证据资格检查，不训练、
不运行模型评测、不使用GPU。初步读取已发现PLS test路径含Windows分隔符及重复split前缀，
且Cherry_powdery_mildew没有训练/验证标注；以下为在这些发现之后固定的完整审计范围。

- 覆盖注册的PLS train/val/test、SDD train/val、WHEAT train/val。
- 逐图核验原路径、修正路径、可读取性、真实尺寸与声明尺寸；保存文件SHA256及解码RGB像素SHA256。
  跨split同时比较文件和像素相同的样本，报告重复组及参与图数；不把“无完全重复”当作排除近重复。
- 按实际加载规则排除background/crowd，核对类别ID/名称一致性、图/标注ID唯一性、孤立标注、
  有限且正尺寸的bbox、每类图数/标注数、训练中未见的评测类别。类别不重编号、不删除困难类别。
- 路径修复只处理分隔符和与image_root完全相同的重复split前缀，已有文件优先；
  不按basename跨目录/跨split寻找替代图片，不改写原始图片或JSON，也不改变已有效的训练/验证路径。
- 核验仓库记录的PLS/WHEAT末步权重是否仍存在。历史AP记录不能替代缺失checkpoint。
  “未发现test使用记录”不等于证明它从未被使用；没有可核对的历史时保留未知状态。
- 只有数据可读、标签一致、没有精确跨split重叠、全部目标类具备训练样本且domain权重可用，
  才把该split标为标准闭集确认已就绪。其余条件分别报告，不将一次audit完成标成模型确认完成。

原始文件保持只读。完整逐图证据和源码快照写入新`runs/v3/data_readiness_*`目录，
小型汇总、类别覆盖、重复列表与hash清单归档到`results/raw/v3_data_readiness*`。
