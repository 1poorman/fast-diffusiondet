协议：DDIM(eta=0) k=10 于全 val 750 图，seed=42，per-image 相对 L2 偏差
`||x0_hat(t) − x0_final|| / ||x0_final||`（300 proposal × 4 坐标联合）。
数据：`results/raw/v2_traj_diag.csv`。

| t | rel_dev mean% | std% | max% |
|---|---|---|---|
| 999 | 48.24 | 8.28 | 75.27 |
| 899 | 42.92 | 7.37 | 69.91 |
| 799 | 38.02 | 6.95 | 62.91 |
| 699 | 33.72 | 6.82 | 55.21 |
| 599 | 29.35 | 6.68 | 50.28 |
| 499 | 25.67 | 6.63 | 47.53 |

| 99（末步=x0_final） | 0 | 0 | 0 |

### V0 判定与解读

1. **H5 的"轨迹近似直线"假设：否定**——噪端偏差 43%（阈值 10%），x0 预测沿轨迹
   漂移显著，ODE 离散误差项并不小。
2. **但这与"求解器无收益"并不矛盾，反而给出更强的机理结论**：
   既然轨迹弯曲大（10 步 vs 1 步的 x0 输出差 ~48%），若弯曲方向是"精修"，
   多步 AP 应显著更高；实测 AP@NFE1 ≈ AP@NFE10 → **弯曲分量是低分 proposal
   的漂移与置信度重排，对检测输出无增益**。求解器再精确地积分这条轨迹，
   积到的也是同一 AP。
3. 对后续步骤的指导：
   - 支持 **V1（t 对齐）**：t=999 的 x0 预测与其余步差异巨大 → 单步直出质量
     有直接优化空间（这正是 NFE=1 唯一访问的点）。
   - **V4（时间网格）保留**：轨迹既然弯曲，中间点选择不再是无关变量，
     DPP@2 的 t_mid 有真实优化空间（预期收益仍受"漂移无益"压制）。

## 工程发现（三连假象，同根因：迁移初始化静默缺失）

**根因**：会话 shell 无 `FASTDD_PRETRAIN` 时，`weights.py` 的 fallback 路径
`petrain/` 不存在（实际目录为 `pretained/` 历史拼写）→ COCO 迁移初始化被静默
跳过（中文 warning 未被察觉）→ 随机头从头训练。

由此推翻当日三个中间结论：
1. ~~bs16+AMP fp16 数值不稳定~~ —— 随机头早期输出无序框触发 GIoU 断言，
   与 bs/fp16 无关（bs8+AMP 同样崩）；
2. ~~bs16 不收敛~~ —— 无迁移初始化的从头训练在该预算下本就到不了可用精度；
3. 当日全部 LR A/B 与 fp32/AMP 对照实验无效（对照组本身是坏的）。

**修复**：`weights.py` `_PATH_CANDIDATES` 加入 `pretained/`。修复后冒烟
loss@19=17.15 → @39=11.09，与健康轨迹（m8-long：17.8→12.02）吻合。

**附带发现（重要）**：同配置同 seed 重训的运行方差 ~1.4 AP——m8-long 原跑
ddim@1=70.27，本会话 uniform 重训=68.82（配置仅 OUTPUT_DIR 不同）。
运行方差比任何求解器效应大一个量级，单跑对照实验的结论必须带此噪声棒。

## V1：训练-推理 t 分布对齐（H6，2026-09-26）

配置：`sdd.res50.bs8.long`（bs8/LR1e-4/4000it/STEPS3200/fp32），
处理臂 tmix（`TRAIN_T_HIGH_PROB=0.5`，GPU0）vs 控制臂 uniform（GPU1），
同 SEED=40244023、同代码、同日重训。评测 3 seed（0/1/2）、renewal/ensemble 关、
eval bs=32。数据：`results/raw/v2_h6_{tmix,uniform}.csv`。

| solver@NFE | tmix | uniform（同会话重训） | Δ |
|---|---|---|---|
| ddim@1 | **69.25±0.23** | 68.82±0.13 | **+0.42** |
| ddim@2 | 68.31±0.26 | 67.56±0.32 | +0.75 |
| dpm_v3@2 | 69.11±0.21 | 68.73±0.34 | +0.38 |

训练侧佐证：tmix 末段 loss 一致更低（@1999：16.6 vs 17.1→重跑后 2.7 vs 2.5 量级互换，
单跑 loss 差异不构成独立证据）。

### V1 判定

- **名义 Gate 达成**：ddim@1 Δ=+0.42 ≥ +0.3 ✅，且 dpm_v3@2 未退化（+0.38，R1 解除）；
- **但必须带噪声棒解读**：同配置重训的运行方差 ~1.4 AP（m8 70.27 vs uniform 68.82）
  远大于 Δ=+0.42。单对训练臂无法把 +0.42 从运行噪声中区分出来。
- **终判：H6 证据不足**（方向正确、量级可疑）。严格判定需 ≥3 对训练臂
  （~3 h GPU）；工程上更便宜的替代：直接用 V4（t_mid 搜索）在推理侧获得
  确定性的、无训练方差的同 ckpt 增益。
- 注意：两臂均低于 m8 原跑（70.27/70.36）——当前最佳 ckpt 仍是
  `output/lab/sdd.res50.bs8.long/model_final.pth`。

## V4：DPP@2 的 t_mid 网格搜索（2026-09-26）

协议：m8 最佳 ckpt（70.27/70.36），k=2 确定性 ODE（eta=0 路径，与 DPP@2 同构），
自定义中间点 t_mid ∈ {300..950}，3 seed，renewal/ensemble 关，eval bs=32。
数据：`results/raw/v4_tmid_{a,b}.csv`（双卡分片）。

| t_mid | AP (3 seed) | Δ vs 默认(500) |
|---|---|---|
| 300 | 67.82±0.23 | −1.19 |
| 400 | 68.57±0.10 | −0.43 |
| **500（默认均匀网格）** | 69.00±0.19 | — |
| 600 | 69.43±0.10 | +0.43 |
| 650 | 69.32±0.03 | +0.32 |
| 750 | 69.85±0.13 | +0.85 |
| 850 | 70.20±0.28 | +1.20 |
| **950** | **70.23±0.19** | **+1.23** |

### V4 判定与解读

1. **t_mid 单调趋近 T**：AP 随 t_mid→999 单调上升，950 处 +1.23 vs 默认网格。
   这解释了两件事：① 为何 v1 矩阵里 DPP@2（logSNR 网格，t_mid 偏晚）是唯一甜点
   而均匀 DDIM@2 很差；② k=2 的"最优时间分配"是把第一步压到极小
   （999→950 几乎不动），本质是"单步直出 + 一次以更新后框为输入的复评"。
2. **但没有超过单步**：t_mid=950（70.23±0.19）vs ddim@1（70.27±0.14，同 ckpt）
   ——噪声内相等；vs DPP@2 logSNR（70.36±0.13）也一致。
   **k=2 的可达上限就是单步 AP 的复现，多出的一次 head forward 无增益。**
3. 与 V0 互证：轨迹噪端弯曲 43% 但 t_mid=950 的"弯曲段"几乎不消耗步数预算
   也能达到同样 AP → 弯曲分量确实对检测输出无贡献（V0 判断成立）。
4. **H-V4 终判：否定（作为加速手段）**。若必须 2 步，用 t_mid≈950（或直接
   DPP@2 logSNR）；但追求"检测速度"时 NFE=1 仍是帕累托最优——两步方案
   至多打平单步，不可能超越。

### V0–V4 汇总：多步/求解器轴就此关闭

| 证据 | 结论 |
|---|---|
| V0：轨迹弯曲 43% 但与 AP 无关 | 离散误差不是精度瓶颈 |
| V4：最优 2 步 = 单步 AP | NFE=2 无增益，NFE=1 帕累托最优 |
| V1：t 对齐 +0.42（< 运行方差 1.4） | 训练侧对齐方向正确但需多样本判定 |
| v1 全系列：solver 间差 ≤1.3 且随训练增强递减 | 求解器替换无红利 |

**后续唯一有红利空间的方向：训练侧**（V2 self-cond / V3 SNR_SCALE / V5 蒸馏），
且都必须用 ≥3 训练臂对运行方差（~1.4 AP）做统计判定。
